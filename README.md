# Address Interiors

A modern web application for Address Interiors - Luxury & Architectural Interior Design Solutions.

## 🚀 Built With

- **React 19**
- **Vite**
- **Tailwind CSS**
- **Framer Motion**
- **Lucide Icons**

## 🛠️ Getting Started

### Installation

```bash
npm install
```

### Running Locally

```bash
npm run dev
```

### Building for Production

```bash
npm run build
```
